## What Is Katalon?

Katalon Collections is a metadata management system for galleries, libraries, archives, and museums.

The domain data lives in seven core types: Objects, Entities, Places, Occurrences, Collections, Storage Locations, and Procedures (loans, acquisitions, conservation). Fields, forms, and controlled vocabularies with authority-data integration can be flexibly customized.

Background on motivation and principles: [About Katalon Collections](/katalon-docs/en/ueber/).
