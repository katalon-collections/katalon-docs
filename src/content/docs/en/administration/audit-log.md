---
title: Audit Log
description: Track, filter, and trace every change to a record.
---

The audit log records every change to holdings data without gaps: who changed what, and when — including the old and new value for each field. It cannot be disabled and cannot be manipulated by editors.

The cross-type overview is available in the admin UI under **Audit Log**; each individual record also shows its own history in the edit form.

---

## Logged actions

| Action | Description |
|---|---|
| **Created** | New record created. |
| **Changed** | Metadata field(s) changed — with old/new value per field. |
| **Deleted** | Record deleted. |
| **Published** | Status change (e.g. draft → published). |
| **Media added / changed / deleted** | Changes to attached media files. |
| **Relation added / changed / deleted** | Relations to other records. |
| **AI schema assistant used** | Request to the [AI schema assistant](/katalon-docs/en/administration/schema/#ai-schema-assistant) with record type, subtype, model, and token consumption. The request is logged, not the fields created afterwards. |
| **AI translation created** | Generated [translation proposal](/katalon-docs/en/administration/mehrsprachigkeit/#ai-assisted-translation) for a multilingual field with model, source, and target language. Logged when the proposal is generated, even if it is discarded afterwards. |
| `ai_complete` | Generated [AI suggestion for a field](/katalon-docs/en/administration/schema/#using-ai-suggestions-in-the-form) with field name, model, and token consumption, also logged when generated. |
| `nl2sparql_generated` | SPARQL query generated by the [AI query assistant](/katalon-docs/en/integration/sparql/#ai-query-assistant) with input text, model, and token consumption. |

For `ai_complete` and `nl2sparql_generated`, the interface currently shows the technical identifier instead of a label.

Batch edits appear as individual entries per affected record, but share a common batch identifier — see [Batch Editing](/katalon-docs/en/administration/batch-bearbeitung/).

## Marking AI-generated field values

Independent of the audit log, Katalon marks individual field values generated by the AI assistant (text suggestion or translation) directly in the edit form with a small **"AI"** icon next to the field. Hovering over it shows the model name and creation timestamp (`AI-generated (<model>) on <timestamp>`).

If a suggestion is edited before applying it, the marker remains on text and rich-text fields as long as the applied text still largely matches the suggestion (similarity above 70%). For other field types, it remains only if the value is unchanged.

This marker (`ai_provenance`) is available for all seven core types: objects, entities, places, occurrences, procedures, collections, and storage locations.

## Filtering and searching

![Complete change history in the audit log with action filters and field changes](../../../../assets/screenshots/administration/audit-log-diff.png)

- **Full-text search** across record labels and changed values.
- **Date range** via from/to date.
- **Action type** filter bar (All, Created, Changed, Deleted, Published, Media, Relation).
- Results are paginated (50 entries per page).

Clicking the record name in an entry opens the affected record directly in the editor — even across record types (e.g. from an entity to an object linked via a relation).

---

## Retention

Audit log entries are not automatically deleted or rotated. They remain even after the associated record is deleted, thereby also documenting the time of deletion and who performed it.
